##  Web Server Security.

###  HTTPS (Hypertext Transfer Protocol Secure)
Our research has led us to conclude that implementing a secure web server involves protecting **communications, data, and user access** to ensure the reliability of our website.

*   **Encryption:** It uses **SSL/TLS** certificates to encrypt communication between the user and the server.
*   **Authentication:** It allows for the validation of the server's identity to the client.
*   **Data Protection:** It ensures the integrity of sensitive information, such as:
    *   Login passwords.
    *   Billing and payment data.
    *   Personal information.

---

###  Two-Factor Authentication (2FA).
**Two-Factor Authentication** adds a critical layer of security to every login session, drastically reducing the risk of unauthorized access.

In addition to the traditional password (**something you know**), users must verify their identity through a second method (**something you have**):

1.  **Authentication Apps:** Temporary codes (TOTP) generated by apps like *Google Authenticator*.
2.  **Messaging:** Receiving codes via SMS or email.
3.  **Hardware:** Using physical security keys.

## Installation of PostgreSQL and PgAdmin4.
* **Postgres**: 
    * For the installation of postgres we used this following commands:
          * apt install postgresql
    * To make the repository configuration we used this ones:
          * sudo apt install -y postgresql-common
          * sudo /usr/share/postgresql-common/pgdg/apt.postgresql.org.sh precise
* **PgAdmin4**:
    * For the installation of pgadmin4 we used this following commands:
          * sudo sh -c 'echo "deb [signed-by=/usr/share/keyrings/packages-pgadmin-org.gpg] https://ftp.postgresql.org/pub/pgadmin/pgadmin4/apt/noble pgadmin4 main" > /etc/apt/sources.list.d/pgadmin4.list && apt update'
          * sudo apt install pgadmin4
    * To configurate the web server we used this one:
          * sudo /usr/pgadmin4/bin/setup-web.sh
